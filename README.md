# Bakalaura_darbs

## Requires
The following libraries are required:
* lxml
* python-docx
* base64
* re (regex)
* copy
* pathlib
* random
* time
* typing
* win32com
* shutil
* csv
* collections
* itertools
* setuptools

## Steps
1. Clone via SSH
2. Install necessary libraries
3. Uninstall if exists py -3.13 -m pip uninstall Bakalaura_darbs
4. Run py -3.13 -m pip install -e .
